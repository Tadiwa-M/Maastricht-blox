# A no-credits day

## Pick one (an hour each)

- [ ] One curriculum track: read, do the exercise, answer the check questions (`node learn/tools/quiz.mjs <track>`).
- [ ] Play for 20 minutes with a notebook. Write every bug as: what you did, what happened, what you expected.
- [ ] Tune one look by hand (`TITLE_FX`, `PALETTES`, the `manga()` grade). Screenshot before and after.
- [ ] Trace one feature end to end: from the key you press to the pixels that change. Write down every file it touches.
- [ ] Write one spec (below) for the next agent session.
- [ ] Read one case study and explain it to someone without notes.

## The spec template

Write these into `PLAN.md` (or a note) before credits return. A good spec turns a vague agent session into a short one.

```text
Feature: <one line>
Why: <what's wrong now, from playing; screenshot if visual>
Done when: <observable results, e.g. "hip-fire: the gun covers < 10% of the screen; aiming raises it in 0.2 s">
Files I think are involved: <from your own tracing>
Not in scope: <what must not change>
How to check: <the test, the screenshot, the button to press>
```
